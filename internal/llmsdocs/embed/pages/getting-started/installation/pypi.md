# PyPI

> Install datamitsu via pip, uv, or pipx

# PyPI (pip / uv)

Install with pip:

```bash
pip install datamitsu
```

Or with [uv](https://docs.astral.sh/uv/):

```bash
uv pip install datamitsu
```

For a global CLI tool, use [pipx](https://pipx.pypa.io/) or [uv tool](https://docs.astral.sh/uv/guides/tools/):

```bash
pipx install datamitsu
# or
uv tool install datamitsu
```
