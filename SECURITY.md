# Security Policy

## Project Status

datamitsu is currently in **alpha**. The API and configuration format are not yet stabilized.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities using GitHub's [private vulnerability reporting](https://github.com/datamitsu/datamitsu/security/advisories/new).

You can also find the "Report a vulnerability" button on the [Security tab](https://github.com/datamitsu/datamitsu/security).

We will respond as soon as possible and release a fix depending on severity and complexity.
