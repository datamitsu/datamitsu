# Scoop (Windows)

Add the datamitsu bucket and install:

```powershell
scoop bucket add datamitsu https://github.com/datamitsu/scoop-bucket.git
scoop install datamitsu
```

To upgrade to the latest version:

```powershell
scoop update datamitsu
```
